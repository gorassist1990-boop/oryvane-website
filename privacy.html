Privacy Policy

Effective date: 11 November 2026

This policy covers two things: this website, and the ORYVANE publishing tool, a private application that connects to YouTube through Google OAuth. ORYVANE is an AI-assisted music project run by an individual owner; it is not a registered company.

1. This website

This website is a set of static pages hosted on GitHub Pages. It has no user accounts, forms, cookies, analytics or tracking scripts, and it loads no third-party resources. ORYVANE does not collect any information about visitors.

GitHub, which hosts the site, may process technical data such as IP addresses in its server logs to deliver and secure the service. That processing is governed by the GitHub General Privacy Statement.

2. Who uses the ORYVANE publishing tool

The publishing tool runs only on the owner's own Windows computer and is used only to manage the owner's own YouTube channel. It is not offered, sold or distributed to other people, and no other user's Google account is connected to it. Before saving any authorization, the tool checks that the Google account grants access to the expected ORYVANE channel and refuses any other channel.

3. Google OAuth permissions requested

Authorization happens only when the owner deliberately starts it. The owner signs in on Google's own consent screen in a web browser; the tool never sees the Google password. The tool requests the following YouTube Data API scopes:

ScopeWhat it is used for
https://www.googleapis.com/auth/youtube.readonlyConfirm which channel the account owns and read the owner's own video details and public statistics (view, like and comment counts).
https://www.googleapis.com/auth/youtube.uploadUpload new music videos to the owner's channel.
https://www.googleapis.com/auth/youtube.force-sslUpdate the title, description and other metadata of the owner's own videos and set their custom thumbnails.

A separate, read-only authorization uses only the youtube.readonly scope for collecting statistics.

4. What data is accessed

The tool uses these YouTube Data API operations: channels.list (to verify the channel), videos.list (to read the owner's video details and statistics), videos.insert (to upload), videos.update (to edit metadata) and thumbnails.set (to set thumbnails).

The tool does not access Gmail, Google Drive, contacts, calendars, the Google account's profile details, or any other Google service. It does not read comments, subscriber lists or information about individual viewers.

5. How the data is used

  • Publishing the owner's own releases and keeping their metadata and thumbnails correct.
  • Tracking how the owner's own videos perform over time.
  • Producing content-planning suggestions for future releases. For this, aggregate statistics of the owner's own videos (video IDs, publication times, and view, like and comment counts) may be sent to an AI model provider (OpenAI) through its API. No OAuth tokens, passwords or viewer information are sent.

Data received from Google APIs is not sold, not used for advertising, and not shared with anyone except as described above. ORYVANE's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Local credential storage

  • OAuth tokens (access and refresh tokens) are stored only on the owner's computer, in the Windows user profile under %LOCALAPPDATA%\ORYVANE\.
  • The token files are encrypted with the Windows Data Protection API (DPAPI), which binds them to the owner's Windows user account, and the folder's permissions are restricted to that user and the operating system.
  • Tokens are never uploaded to any ORYVANE server (ORYVANE operates none), never published in this website or in source code, and are sent only to Google when the tool calls Google's APIs.
  • The tool's own logs are designed to exclude tokens and OAuth callback addresses.

Video statistics collected by the tool are stored in local files on the same computer and are kept for as long as the owner needs them for performance tracking. The owner can delete them at any time.

7. How to revoke access

  1. Open your Google Account's third-party access page at myaccount.google.com/connections (also reachable through Google Account → Security → Your connections to third-party apps & services).
  2. Select the ORYVANE app and choose to remove or delete all connections.

After revocation, Google rejects the stored tokens and the tool can no longer access the channel. The encrypted token files can also be deleted from %LOCALAPPDATA%\ORYVANE\ on the owner's computer.

8. Google and YouTube policies

The publishing tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

9. Children

This website and the publishing tool are not directed at children and collect no information from them.

10. Changes to this policy

If the tool's data practices change, this page will be updated and the effective date above will change. The full history of this page is public in its GitHub repository.
